# Limitations and unperformed research

The project is an exploratory synthetic engineering case study. It is not a deployed UPI integration, production detector or real-world fraud-prevention validation.

## Current scientific boundaries

- **Provenance:** New pilot GE exclusion is bound to registered synthetic inputs/grammar. Historical detector-family ancestry is unavailable.
- **Discrimination:** Legitimate GE mimic blocking is substantial; mechanism exclusion is not sufficient evidence of useful fraud discrimination.
- **Coverage:** Four legacy families are implemented, but only HVB/GE occur in the matched pilot. More mechanisms are future work.
- **Fairness:** Online actions/budgets are matched; offline learning costs differ. Label-blind RL retains reward-mediated feedback.
- **Inference:** Nine independent blocks, related contexts, six unadjusted descriptive contrasts and no prospectively powered confirmatory lockbox.
- **Metrics:** Gross flow is not victim loss; blocked proposals are not savings. Timing means are conditional on event occurrence.
- **External validity:** No bank/NPCI/UPI dataset, real behavior calibration, human-investigation process or deployment latency validation.

## Engineering boundaries

Linux/WSL2/Python 3.11 is tested. Native Windows/macOS portability, untrusted pickle loading, internet exposure, formal security certification and full accessibility certification are not established. The legacy runner requires Git context. The dashboard intentionally does not execute arbitrary commands or unsupported per-arm pilot selections.

## Analysis versus new experiments

Existing records permit additional stratification, paired summaries, event/censoring descriptions, confidence sensitivity and reproducibility checks. They cannot retroactively create absent historical ancestry, real-world data, blinded lockbox custody or prospective power.

New data/experiments would be required for external validation, realistic benign calibration, feature ablations, broader mechanism tests, fully offline-cost-matched learning controls and a powered confirmatory study. These are not implemented by this integration, and Gate C remains HOLD.
