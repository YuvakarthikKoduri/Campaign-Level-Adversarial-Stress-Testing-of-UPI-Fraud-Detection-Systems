# Contributing

Use a dedicated branch and preserve baseline SHA, raw evidence, failures and uncommitted work before editing. Never alter results to improve outcomes, weaken assertions to inflate passes, or count overlapping selections as new distinct tests.

Install the lock, restore verified evidence and run the exact README regression selection plus the smallest relevant short demo. Add regression coverage for reproducible defects. Record commands, exit codes, scope and limitations; do not rerun expensive full studies without a methodological reason.

Separate engine/data changes from documentation or dashboard work. A changed source identity requires appropriately versioned new output, not edits to old manifests. Scientific claims need identified records, units, denominators and supported scope; published claims need genuine citations.

Do not commit credentials, virtual environments, generated caches, local job state, sensitive identifiers or redundant large raw trees. Keep third-party notices/licenses intact. Do not expose arbitrary execution or a public dashboard.

Use the PR template and inspect the full diff. No direct default-branch push, merge, release or Gate C execution is authorized by this package. Gate C remains HOLD.
