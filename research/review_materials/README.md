# Faculty review materials

Use the [demonstration script](../../docs/REVIEW_DEMONSTRATION.md), [presentation outline](presentation_outline.md) and [faculty Q&A](questions_and_answers.md) together. The nine-slide [editable deck](review_deck.pptx) uses native text, shapes, tables and charts plus a cropped screenshot of the actual integrated dashboard.

The deck is generated from verified tables by `python scripts/build_review_deck.py`. That optional build step requires `python-pptx==1.0.2` and Pillow in an authoring environment, not the dashboard runtime. Liberation Sans is the deck font; install it or inspect the rendered PDF preview when another platform substitutes fonts.

The [PDF preview](review_deck.pdf) was rendered from the PPTX with LibreOffice and visually checked after correction. The paper, deck and reports are drafts for researcher approval, not evidence that either university checking threshold has been met. See [external checks](EXTERNAL_CHECKS.md).
